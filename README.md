# Weather Dashboard - Asynchronous JavaScript & RESTful APIs

A real-time Weather Dashboard web application built using JavaScript, HTML5, CSS3, and the OpenWeatherMap REST API.

## Features
- **Real-Time Data**: Fetches live temperature, humidity, and wind speed using `async/await` and Fetch API.
- **Search Functionality**: Allows users to search weather conditions by city name.
- **Error Handling**: Displays user-friendly error messages for invalid city names or network issues.
- **Responsive UI**: Designed to adapt seamlessly across desktop and mobile screens.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+ / Fetch API)
- OpenWeatherMap REST API
